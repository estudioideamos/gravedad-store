# Seguridad

## Versiones cubiertas

Se mantiene únicamente la versión desplegada desde la rama `main`.

## Reportar una vulnerabilidad

No abras un issue público con credenciales, datos personales, rutas privadas ni detalles que permitan explotar el sitio.

Contactá de forma privada a Estudio Ideamos mediante [ideamos.com.ar](https://ideamos.com.ar/) e incluí:

- descripción del problema;
- pasos mínimos para reproducirlo;
- impacto estimado;
- versión o commit afectado;
- evidencia sin datos personales ni secretos.

Las credenciales expuestas deben revocarse y reemplazarse de inmediato; eliminarlas de un commit nuevo no las quita del historial.
